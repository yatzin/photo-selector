# Text clip fonts

The fonts text clips can use (lib/video/fonts.ts). Each is a Google Fonts static TrueType file, unmodified (not subset by this project), with its licence text beside it in this folder. The newer files (from Great Vibes on) are the Latin static instances Google Fonts serves (fonts.gstatic.com, through google-webfonts-helper).
